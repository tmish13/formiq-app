## Change (`audit/g17-ci-truth`)

- **One backend workflow, `backend-tests.yml`** (kept: it already ran in `backend/` on Python 3.11 with
  the right job split). Unit/API job: the secret is now 46 characters; Postgres 15 and Redis 6 services
  with the same `POSTGRES_*` names the compose stack uses; system packages the image installs
  (`ffmpeg libpq-dev libmagic1`) plus `libgl1 libglib2.0-0` for OpenCV on a runner; two new steps before
  the tests — `python -m app.core.image_check` and `alembic upgrade head && alembic check`. The push
  trigger no longer restricts to `main`/`staging`, so a branch push runs the unit gate (path-filtered to
  `backend/**`). Integration and e2e jobs unchanged apart from the secret.
- **One frontend workflow, `frontend.yml`**: Node 20 (`package.json` engines), `npm ci`, `npm run
  typecheck`, `npm test -- --ci`. `frontend/jest.config.js` now ignores `tests/broken-tests-backup/`
  (10 parked suites jest was collecting).

  `frontend-tests.yml`.
