## Keypoint Data Format
Each keypoint JSON file contains an array of frames with 33 landmarks per frame:
```json
[
  {
    "frame_index": 0,
    "landmarks": [
      {
        "x": 0.5073054432868958,
        "y": 0.15492580831050873,
        "z": -0.13957475125789642,
        "visibility": 0.9999688863754272
      },
      // ... more landmarks (33 total)
    ]
  },
  // ... more frames
]
```
